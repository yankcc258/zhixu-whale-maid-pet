# 希可迷你版 · 女仆装概念

本套为约二头身的完整概念立绘：头部约占站立身高的一半，身体圆润、四肢短小。保留蓝色长发与呆毛、鲸鱼耳鳍、蓝眼、角色左侧（正面观看时画面右侧）的青蓝蝴蝶结，以及深蓝白色女仆装。

## 制作与校验

使用内置 imagegen 绘制待机基准稿，再据同一基准生成表情、走路和坐姿；坐姿边缘及第二帧步态进行了定点修整。最终统一缩放、透明边缘整理与画布排版，不改变人物设计。

`generation-prompts.md` 保存实际生成提示词，`validation.json` 保存图片尺寸、透明通道、脚底基线与文件哈希，`SHA256SUMS.txt` 可校验全部交付文件。文本统一 LF 换行，以保证 Windows 副本与仓库文件的字节校验一致。
