# 第二批：眼珠修补 + 冬装 + 被炉

规则照 `换装拆层模板_v05.md`。**底稿用 `seeko_v05/seeko_cubism_import_v05c.psd`**（v05d 的头发修补有浅色色块和竖接缝、眼珠变暗变平，见 `seeko_v05/露娜检查_v05c对比v05d脸部.png`，先不用）。

## ① 眼珠修补 v05e（先做，最小改动）

- 复制 v05c，**只改 IrisPupil_R、IrisPupil_L 两层**，其余 80 层逐像素不动。
- 去掉眼珠顶上那道深色月牙，画成干净的完整竖椭圆；**颜色、亮度、高光位置照 v05c 原样**（不要变暗、不要变平）。
- 交 `seeko_v05/seeko_cubism_import_v05e.psd` + 一张和 v05c 的眼睛放大对比图。

## ② 冬装 winter

- 参考 `参考_冬装立绘.webp`：白色毛绒长外套（牛角扣）、红格子围巾、白色毛线帽带大绒球、棕色短靴。
- 槽位建议：外套 → DressBase（+ ChestLace/ApronBody 放扣子、口袋）；袖子 → ArmUpper/ArmLower；毛绒袖口 → Cuff；围巾 → NeckCollar + NeckBow_R/L（垂下的两条）；帽子 → Headband；裤袜 → LegStocking；靴子 → Shoe。
- 手里**不拿杯子**（手是共用层，两手自然下垂）。帽子盖住头顶但别挡住呆毛根部太多；呆毛、刘海、耳鳍不改。

## ③ 被炉 kotatsu（试验）

被炉是道具场景，骨架里下半身那块是**不动的**，所以可以把被炉画进下半身的槽位：
- 上半身：穿家居棉袄（半缠，蓝白格子或深蓝），袖子照常。
- **被炉桌 + 被子画进 SkirtFront**（盖住腰以下），**桌面和橘子篮画进 SkirtHemLace**；LegStocking、Shoe、DressBase 下半截留空或只画被子里露出的部分。
- 被炉可以比身体宽（左右各到 x≈80～1006 都行），但**上边别超过腰线**，手臂自然下垂时放在桌面后面也没关系（抬手动作会从桌后抬起来）。
- 参考 `参考_被炉立绘.webp` 的配色（蓝白格子被、木桌面、橘子）。
