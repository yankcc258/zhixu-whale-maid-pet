# Seeko v03.5 修图候选补丁

基准：art-inbox/art/live2d/seeko_v03_4。仅包含十二张替换图层 PNG；原 PSD、绑定文件和其他图层均未修改。

- 所有 PNG：1086×1448 RGBA，偏移 (0,0)，图层名不变。
- HairBack_L / HairBack_R 使用原画布已对齐的 Reserve_BackHair 干净后发，并沿原左右分层范围分配（L: x≥488，R: x<599），保留中间重叠。无耳鳍、袖口、手指或手臂残片。
- ArmUpper、ArmLower、Cuff、Hand、FinEar 的左右层补入相邻后发中可辨认的原描边；未更改部件坐标。
- 刘海及其投影等其他图层未修改。

## 验证与限制

已重新解码输出 PNG，核对画布、透明通道、名称和哈希；按 v03.4 清单的可见性与顺序合成默认姿势，并检查后发单独显示。

这是一份候选替换补丁，并非最终绑定验收版本。干净备用后发与 v03.4 原可见后发的局部发束、轮廓及高光存在差异，因此默认画面不是逐像素一致，也不能保证完全无可见变化。部件连接处和补回描边需在当前 v04 模型中复查。未运行 Cubism 的实际参数极值、物理或动作验收。

请只将 layers_png 下同名文件替换进现有 PSD，保留图层名称、顺序、坐标与绑定。预览 seeko_neutral_v03_5_candidate.png 为静态参考，不是替换图层。
