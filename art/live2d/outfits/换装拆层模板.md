# 希可 Live2D 换装拆层模板

Live2D 的动作都绑在「骨架」上（头、身体、手臂的变形器和参数），图层只是挂在上面的「皮」。
新衣服**按同样的图层名、同样的位置**画，露娜把它导进模型的副本时，Cubism 会按图层名自动替换图片，
所有绑定（转头、呼吸、挥手、头发物理、表情、动作）都能直接沿用。

## 底稿

- 用 `art/live2d/seeko_v03_6/seeko_cubism_import_v03_6b.psd`（82 层）**复制一份**来改。
- 画布 **1086×1448**，图层位置、名字、上下顺序**一律不变**，也不要新增或删除图层。
- 姿势和现在的女仆装完全一样（两手自然下垂、手掌朝外、双脚并拢站），身体比例不变。
- 对照图：`换装图层示意.png`（右边彩色标出了每个要换的槽位）。

## 只改这 25 层（衣服槽位）

| 图层名 | 槽位 | 说明 |
|---|---|---|
| DressBase | 衣服主体 | 上衣 + 下半身主体（连衣裙、睡衣上衣、T 恤……）。**必须盖住原来女仆裙的范围**，下面没有皮肤 |
| SkirtFront | 下摆前片 | 裙子/上衣下摆的前片；没有就留空 |
| SkirtHemLace | 下摆边 | 下摆的边（花边、松紧边、裤腿口）；没有就留空 |
| BodiceWhite | 胸前内衬 | 胸口中间露出来的那块；没有就留空 |
| ChestLace_R / ChestLace_L | 胸前两侧装饰 | 门襟、口袋、花边；没有就留空 |
| ApronBody / ApronLace | 前罩 | 围裙、外套前片、实验服前襟；没有就留空 |
| Waistband | 腰带 | 腰带、松紧腰；没有就留空 |
| NeckCollar | 领子 | |
| ArmUpper_R / ArmUpper_L | 上臂袖子 | 肩到手肘；**肩膀那头要画到被身体盖住的地方**（抬手时会露出来） |
| ArmLower_R / ArmLower_L | 前臂袖子 | 手肘到手腕；短袖的话这里画**皮肤**（手臂） |
| Cuff_R / Cuff_L | 袖口 | 没有就留空 |
| LegStocking_R / LegStocking_L | 腿 | 袜子/裤腿；光腿就画**皮肤** |
| Shoe_R / Shoe_L | 鞋 | 拖鞋、运动鞋、靴子 |
| Headband | 头饰 | 帽子、发箍、兜帽；没有就留空。**刘海、头发不在这层** |
| HairRibbon_L | 发饰 | 发夹、发绳；没有就留空 |
| NeckBow_R / NeckBow_L / Sapphire | 颈饰 | 领结、围巾、领带；没有就留空 |

「留空」= 这一层保持图层、内容全透明。

## 不要动的 57 层

头发（HairBack/HairSide/HairFront/Ahoge）、脸（FaceBase、FaceHairShadow*、Neck）、眼睛、眉毛、嘴、脸红、耳鳍（FinEar）、**手（Hand_R / Hand_L）**。
这些所有衣服共用，原样保留。

## 画法要求

1. **每层都画完整**：被别的层挡住的地方也要画（比如袖子在身体后面那截、衣服在手臂后面那块），因为转身、抬手时会露出来。
2. **自带描边**：每层自己的外轮廓线画在自己层里，不要画到别的层上。
3. **不要把别的部件画进来**：袖子层里不要有手、头发，衣服层里不要有袖子。
4. 默认合成出来要像一张完整的立绘：没有缝、没有露出透明的洞。
5. 衣服可以比女仆装宽松一点，但别超出女仆装范围太多（每边 30px 以内），太大的话身体的变形框框不住。

## 交付

- 每套衣服一个文件夹：`art/live2d/outfits/<衣服英文名>/`
- 放：`seeko_outfit_<衣服英文名>.psd`（完整 82 层）+ `preview.png`（默认合成图）
