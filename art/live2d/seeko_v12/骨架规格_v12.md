# 希可 Live2D 骨架 v12 规格（草案）

目标：解决「只有头和四肢在动」「动作像机器人」「拎起来很怪」。做法是把**身体做活**（分段 + 跟随 + 形变），动作改成**少而精、手调节奏**。先在女仆装上立住，再按同一脚本搬到睡衣 / 冬装 / 被炉。

依赖：特蕾莎的 v12 拆层 PSD（`需求/v12拆层需求.md`）。

## 二、变形器树（女仆装）

```
ROOT
├ [warp] 全身拉伸 ParamBodyStretch            ← 以脚底为锚，纵向拉伸
│  ├ [warp] 臀段 BodyAngleX/Z, Hip, BodyAngleY
│  │  ├ [warp] 裙摆 SkirtX, SkirtY             ← SkirtBack, SkirtFront, SkirtHemLace, SkirtInner
│  │  ├ [warp] 围裙 Apron                      ← ApronBody, ApronLace
│  │  ├ [rot] 左大腿 LegL (+BodyAngleY 缩短)   ← LegThigh_L
│  │  │  └ [rot] 左小腿 KneeL                  ← LegShin_L, Shoe_L
│  │  └ [rot] 右大腿 / 右小腿 同上
│  │  └ [warp] 腰段 BodyAngleX/Z               ← Waistband
│  │     └ [warp] 胸段 BodyAngleX/Z, ChestZ, Breath ← DressTop, BodiceWhite, ChestLace, NeckCollar, Sapphire, NeckBow
│  │        ├ [rot] 左肩 ShoulderL（平移为主）
│  │        │  └ [rot] 左上臂 ArmLA            ← ArmUpper_L
│  │        │     └ [rot] 左小臂 ArmLB         ← ArmLower_L, Cuff_L
│  │        │        └ [rot] 左手 WristL       ← Hand_L, HandOpen_L（HandL 切换显隐）
│  │        ├ 右肩 / 右上臂 / 右小臂 / 右手 同上
│  │        └ [warp] 脖子曲面 (Stretch 时拉长)  ← Neck
│  │           └ [rot] 面部旋转 AngleZ（轴心脖子，v09 已有）
│  │              ├ [warp] 头部曲面 AngleX/Y（现有，补全下巴透视）
│  │              │  ├ 脸部曲面 …（现有，不动）
│  │              │  ├ 前发/侧发 …（现有）
│  │              │  └ 呆毛/耳鳍 …（现有）
│  │              └ [warp] 后发整体 HairBack, HairBackY
│  │                 ├ [warp] 后发外缕L HairBack1 ← HairBack_L_Outer
│  │                 ├ [warp] 后发中缕L HairBack2 ← HairBack_L_Mid
│  │                 ├ [warp] 后发内缕L HairBack3 ← HairBack_L_Inner
│  │                 ├ 右侧三缕同上
│  │                 └ HairBack_Under（只跟整体，不单独摆）
```

要点：
- 躯干三段**串联**（臀→腰→胸），每段只转/倾一点点（臀 20%、腰 30%、胸 50%），叠起来就是弯腰而不是平移。
- 肩是「平移」旋转器（耸肩），上臂旋转器挂在它下面；肩球画在袖笼后，所以上臂转 90° 时袖笼不破。
- 手腕旋转器下面挂两只手（握拳/张开），`ParamHandL` 控制显隐。
- 后发：整体一个曲面（跟头、跟拎起上下浮），三缕各自一个小曲面挂物理，刚度外缕最软。
- `全身拉伸` 放在最外层，拎起时整个人被拉长、重心下沉由它和 BodyAngleY 一起做。

## 三、关键形态：哪些能算、哪些要手捏

**能用 rigedit 算出来**（结构 + 线性形变）：所有旋转器的角度键、三段躯干的倾/弯（按行线性剪切）、全身拉伸（纵向缩放）、裙摆左右/上下、后发缕摆、脖子拉长、耸肩平移。
**要在 Cubism 里用眼睛捏**（露娜先捏粗版，主人改）：
1. 头部曲面 AngleX/Y 的下巴、脸颊透视（现在只有一点）。
2. 上臂举到 90° 时袖笼和泡泡袖的鼓起（旋转器只会转，泡泡袖的形状要用上臂自己的关键形态补）。
3. 裙摆 SkirtY=-1（下垂贴腿）和 +1（鼓起）的轮廓。
4. 弯腰到极限时围裙/腰带的压缩。
5. 拎起（Stretch=1 + BodyAngleY=-10）的整体轮廓检查。

## 五、动作：重做的原则（make_motions_v3）

1. **不再用正弦**。每个关节一条关键帧曲线，贝塞尔缓动（easeOut 为主，预备用 easeIn）。
2. **结构固定**：预备（反向 10～20%，0.1～0.2s）→ 主动作（0.15～0.3s，快）→ 过冲（+10～15%）→ 回弹 → 停顿（0.2～0.5s 什么都不动）→ 缓慢复位。
3. **错帧**：核心（臀）先动，腰 +2 帧，胸 +4 帧，头 +6 帧，手臂 +3 帧，手腕 +5 帧；头发裙子交给物理。
4. **先少后多**：第一批 9 个 —— 待机 ×2（呼吸 + 偶尔换重心）、拎起（Hang：全身拉长 + 下坠 + 腿失控 + 裙摆垂 + 表情惊→委屈随时间变）、落地（Land：压缩 → 回弹 → 裙子鼓）、走路、挥手（手举过头 + 手腕摆 + 身子微倾 + 张开的手）、蹦（Hop：蹲 → 跳 → 落 → 裙摆）、摸头反应（Shy）、惊（Flinch）。做好一个看一个，过了再做下一个。
5. 每个动作渲染成 GIF 给主人看，主人点头才算过。

## 六、运行时叠加层（live2d.js）清理

- 看鼠标：只碰 AngleX/Y、EyeBallX/Y；身体跟随改由 physics 的输入（不再在 beforeModelUpdate 里手写 BodyAngle 补偿）。
- 耳鳍竖起、横拖后仰：并进 Hang / Hover 动作或 physics，`beforeModelUpdate` 里只留嘴型联动和眼珠增益。
- 表情只碰脸部参数（现有的已经是）。
