# 希可 v12 女仆装动画拆层

基于 `seeko_cubism_import_v05f.psd`，画布 1086×1448。PSD 共 104 个满画布图层：72 层逐像素保留、16 层修改、16 层新增，删除被替代的 5 层。脸、眼睛、嘴巴及表情相关 55 层的 RGBA、显隐和相对顺序均与 v05f 一致。原 PSD 未改动。

## 文件

- `seeko_cubism_import_v12.psd`：可导入的分层文件。
- `preview_v12.png`：透明默认合成；`comparison_v05f_v12.png`：同尺寸并排对照。
- `parts_v12_<图层名>.png`：32 个新增或修改图层，每张均为 1086×1448；`parts_v12_contact.png` 是浏览用缩略总表。
- `validation_v12.json`：逐层 RGBA SHA256、名称、顺序、显隐、位置、修改分类和检查结果。
- `validation_v12_arms*.png`、`validation_v12_legs.png`、`validation_v12_neck.png`、`validation_v12_hair.png`：图片层级的压力检查。`stress_v12.json` 为采样结果。
- `krita_default_v12.png`：Krita 独立读回导出，白底。
- `imagegen_prompts_v12.json`：内置 image_gen 的最终补画提示词；后处理仅用于尺寸定位、组装、透明通道清理与检查。
- `manifest_v12.json`：文件校验清单。

## 拆层

手臂补齐圆肩与上下臂圆头重叠；袖口为完整短环，握拳和张手均带圆腕。`HandOpen_R/L` 默认隐藏，使用时与对应 `Hand_R/L` 互斥。

DressBase 删除，改为 DressTop + SkirtBack，并加入 SkirtInner。裙前片、裙花边、围裙向上补足隐藏区域。Neck 为约 192px 高的独立肤色柱，不再混入白色衣领。

LegStocking_R/L 删除，替换为 LegThigh_R/L + LegShin_R/L。膝盖圆头的重叠边使用白袜同色，不画跨过膝盖的深色横线。鞋口补齐。

HairBack_R/L 删除，各替换为 Inner/Mid/Outer 三缕完整长发。新发缕的轮廓与明暗经过重画，默认合成并非 v05f 全身逐像素复刻；脸部原层完整保留。HairSide_R/L 仅补根部余量并清理数个孤立小点。

HairBack_Under 使用连续暗色底片；因六缕的轮廓已重画，底片按新发缕包络内缩约 15px，未机械沿用旧大片后发的全部外伸尖角。已封闭底片内部透明小孔，避免旧尖角从新发缕外露。

## 关节坐标（画布左上为原点，R 是画面左侧）

需求里的右肘和右腕坐标落在身体内部，不能对应原手臂。本版按 v05f 实际部件位置校准，导入后请使用以下轴心：

| 关节 | R | L |
|---|---|---|
| 肩 | (392, 935) | (668, 935) |
| 肘 | (365, 1018) | (700, 1018) |
| 腕 | (307, 1065) | (760, 1075) |
| 大腿轴 | (455, 1170) | (610, 1170) |
| 膝 | (450, 1255) | (620, 1255) |
| 脚踝参考点 | (440, 1325) | (630, 1325) |

上下臂和腿部沿自身方向补圆头，实际隐藏余量大于最低 25px / 20px 要求。自然姿势原本略向外张，压力图中的 90° 是相对默认姿势的旋转量，不代表画面中绝对水平线。Cubism 参数若要把 90 定义为绝对水平，需要按默认骨段方向换算角度。

## 绘制顺序调整

除需求中的拆分替换外，有两处为了遮挡隐藏余量而调整：

1. Neck 放在 DressTop 和 NeckCollar 后方、脸前景之前，防止加长的肤色柱盖住领口。
2. ApronLace / ApronBody 放在 DressTop 之后、BodiceWhite 之前，腰带仍盖在它们上方，避免围裙补出的上沿压住胸前白布。

完整自下而上顺序见 `validation_v12.json` 的 `order_bottom_to_top`。脸部各层的相对顺序不变。

## 验证范围与绑定提示

- 保存后重新打开 PSD，104 层尺寸、名称、顺序及显隐与交付清单一致；55 个脸部与表情层、合计 72 个保留层 RGBA 一致。
- Krita 独立读回成功，白底导出与逐层合成最大 RGB 差为 1，超过 2 色阶的通道数为 0。
- 肩 0/45/90°、肘 0/±90° 的组合，以及大腿 ±25°、小腿 ±40° 的组合，连接处均有不透明交叠。所采样的肩/肘/腕/膝中心圆域覆盖率为 100%；明细包含采样半径对应的测试代码逻辑和重叠像素数，不等同于整幅网格的数学无缝证明。
- 脖子纵向 +15%，配合头部上移 14px，已附合成对照。
- 后发附 ±15° 的整缕刚性旋转极限对照。全组内收时会露出暗色底片；外摆时个别发梢可超出原画布的取景边界。实际物理应按骨架草案使用曲面分缕摆动，检查底片的覆盖和轮廓，避免把整缕刚性旋转直接当最终发型关键形态。
- 默认手部绘制顺序按需求保留在脸与侧发后方。挥手举到脸旁时，请对 Hand / HandOpen / Cuff 做动作绘制顺序切换；独立手臂压力图用于排除头发遮挡后检查接缝。
- 袖口环孔、鞋口、发缕回卷之间的留空为正常结构；alpha 清单中有单独记录。底发、白袜、衣身没有内部透明破洞。

这些检查在分层图片和 PSD 层级完成，未修改或输出 CMO3，也未声称已完成 Cubism 网格、关键形态、物理或运行时验收。导入后仍需按《骨架规格_v12.md》第三节手调肩袖鼓起、裙摆与身体极限形态。
