# PSD2Live 试验记录（2026-10-23）

在云端用 live2d-agent-kit 锁定的 psd2live（commit 5526f2e + kit 补丁）给 v04 底稿做了一次全自动绑定。

## 怎么跑
1. `bash scripts/setup-psd2live.sh --source-only`（需要能连 repo.maven.apache.org、services.gradle.org、plugins.gradle.org、dl.google.com）
2. 把 `RigBuilder.kt` 第 541 行的 `RuntimeTarget.Cubism50` 改成 `Cubism42`：桌宠用的 Cubism Core 4.2 读不了 5.0 的 moc3。
3. `python3 -I seeko_manifest.py <82层.psd> <新目录>`：按 psd2live 认得的名字改层名（63 层；小张嘴、O 型嘴、眼眶遮罩、闭眼眼皮不放）。
4. `bash scripts/export-model.sh <新目录>/manifest.json <输出目录>`：37 秒出 .cmo3 + .moc3 + 物理 + 4 个动作。

## 结果（对比图：psd2live_vs_ours_eyes.png）
- **半睁眼明显比我们好**：它是真的把眼皮往下压、眼珠被裁掉；我们的骨架在 0.2～0.6 之间是睁眼线和闭眼线交叉淡入淡出，有重影。
- **歪头幅度很大**、头发跟着甩，±30 度太夸张，要调小。
- **缺的**：手臂参数、笑眼、腮红、三组嘴型（只有一组张嘴），也没有我们的 12 个动作和 7 个表情。

## 结论
不换掉现有骨架（动作、表情、换装都绑在上面），而是借它的眼皮做法：v05 重新绑定时，把我们闭眼的关键形态改成「上眼线往下压 + 眼白/眼珠跟着压扁」，闭眼线只在快闭上时出现。
